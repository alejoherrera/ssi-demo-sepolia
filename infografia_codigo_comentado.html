Anatomía del contrato SSIAccessControl.sol

Código comentado: cómo un smart contract demuestra los 4 principios de la Identidad Digital Autosoberana (SSI) · Sepolia

Control del titular Divulgación selectiva Temporalidad Revocabilidad Lectura / utilidad

1. Estado y estructura de datos

Variables de estado Control del titular
address public owner;            // el titular (dueño) del dato
string  private personalData;   // el dato protegido
uint256 public defaultDuration; // ventana por defecto (seg)
owner es quien despliega. personalData es private, pero ojo: en la cadena pública el valor igual es visible. defaultDuration en el taller = 864000 (10 días).
struct AccessGrant Divulgación + Temporalidad
struct AccessGrant {
    bool    authorized; // ¿tiene acceso?
    uint256 grantedAt;  // cuándo se otorgó
    uint256 expiresAt;  // cuándo expira
    string  purpose;    // motivo del acceso
}
mapping(address => AccessGrant) accessGrants;
Por cada dirección autorizada se guarda su permiso: a quién, para qué y hasta cuándo.

2. Modificadores (controles de seguridad)

onlyOwner Control del titular
modifier onlyOwner() {
    require(msg.sender == owner,
      "Solo el titular...");
    _;
}
Solo el dueño ejecuta acciones sensibles (otorgar, revocar, rectificar).
hasValidAccess Temporalidad
modifier hasValidAccess() {
    AccessGrant memory g = accessGrants[msg.sender];
    require(g.authorized, "No tienes autorizacion");
    require(block.timestamp <= g.expiresAt,
      "Tu acceso ha expirado");
    _;
}
Deja leer el dato solo si la dirección está autorizada y el permiso no expiró.

3. Funciones clave

constructor Despliegue
constructor(string _personalData, uint256 _dur) {
    owner = msg.sender;
    personalData = _personalData;
    defaultDuration = _dur; // 864000 = 10 días
}
Al desplegar, fija el dato y la duración por defecto.
grantAccess Divulgación selectiva
function grantAccess(address _viewer, string _purpose)
    external onlyOwner {
    uint256 expiry = block.timestamp + defaultDuration;
    accessGrants[_viewer] =
      AccessGrant(true, block.timestamp, expiry, _purpose);
    emit AccessGranted(_viewer, expiry, _purpose);
}
Autoriza a una dirección por la duración por defecto (10 días) y emite el evento AccessGranted.
revokeAccess Revocabilidad
function revokeAccess(address _viewer, string _reason)
    external onlyOwner {
    accessGrants[_viewer].authorized = false;
    accessGrants[_viewer].expiresAt = block.timestamp;
    emit AccessRevoked(_viewer, _reason);
}
Corta el acceso de inmediato. El titular manda, en cualquier momento.
viewData Lectura protegida
function viewData() external hasValidAccess
    returns (string) {
    emit DataAccessed(msg.sender, block.timestamp);
    return personalData;
}
El verificador lee el dato solo con acceso vigente; queda traza con DataAccessed.
updatePersonalData ≈ Rectificación (ARCO)
function updatePersonalData(string _newData)
    external onlyOwner {
    personalData = _newData;
    emit DataUpdated(block.timestamp);
}
El titular rectifica su dato: análogo al derecho de rectificación de la Ley 8968.
